# EasyKey cho Windows
Mở `OpenKey/OpenKey.sln` bằng Visual Studio 2022 và build cấu hình `Release|x64`. Kết quả là `x64/Release/EasyKey.exe` và `x64/Release/EasyKeyUpdate.exe`.

EasyKey chỉ hỗ trợ Windows 11 64-bit. Xem [README](../../../README.md) ở thư mục gốc để biết tính năng và phần ghi công OpenKey.
